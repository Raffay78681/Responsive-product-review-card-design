#Responsive produce review card design.
---
I made it using HTML and CSS and used flexbox properties to arrange the content.  

  
#Challenges.
---
The only challenge I faced adding the overlay on the NFT image to make a transition effect. I overcame it by creating
a wrapper div and an overlay element. I gave the ```position: relative``` to wrapper and ```position: absolute``` to the overlay element
to control its positioning according to the wrapper div.  

Then I added a transition to change the opacity the overlay for ```:hover``` effect.  

#Responsiveness
---
The design is fully responsive for a wide range of screen sizes ranging narrow mobile displays to wide computer screens.
